# Contributing to HealWright

Thank you for your interest in contributing to **HealWright**! We welcome bug reports, feature suggestions, heuristic improvements, and pull requests.

## Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/bombordirocrocodildok-cmyk/healwright.git
   cd healwright
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Build TypeScript in watch mode:**
   ```bash
   npm run watch
   ```

4. **Run the test suite:**
   ```bash
   npm test
   ```

5. **Run the live demo:**
   ```bash
   npm run demo
   ```

## Pull Request Guidelines

- Ensure all TypeScript code compiles without errors (`npm run build`).
- Ensure all tests pass (`npm test`).
- Add tests for any new heuristic matching strategies or parser edge cases.
- Follow Conventional Commits: `feat:`, `fix:`, `docs:`, `test:`, `refactor:`.
